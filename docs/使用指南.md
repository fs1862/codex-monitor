# Codex 旁路监控台使用指南（codex-monitor v3.4）

> 定位：**旁路监控**（只读推断），不读取 Codex 内部协议、不依赖 daemon，任何界面（VSCode 扩展 / CLI / App）发起的 Codex 工作均可被监控。
> 本指南面向二次开发与深度使用；快速上手见 [README](../README.md)。

## 一、它解决什么问题

Codex 工作时的执行过程在界面上是折叠的，人无法高效实时跟读。本监控台在**旁边开一个 PowerShell 窗口**观察：Codex 进程、VSCode 扩展日志、项目文件变化、git diff、**每个会话的 rollout 事件流**（当前正在执行哪条命令、累计 token、本轮是否结束），把状态归纳成一眼可读的面板。**只在有实质变化时重绘**，画面静止 = 一切正常推进中或空闲，不需要盯屏。

## 二、运行

```powershell
cd C:\path\to\your\project
powershell -ExecutionPolicy Bypass -File C:\path\to\codex-monitor-v3.4.ps1
```

启动后确认标题为 `CODEX AGENT MONITOR v3.4`、底部提示含 `redraw on change, min gap 5s`（跑旧版脚本会 2~3 秒闪全屏）。

### 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Project <路径>` | 当前目录 | 监控哪个项目（会话面板 `*` 标记 + git/文件活动都按它算） |
| `-Interval <秒>` | 3 | 后台采集轮询间隔（不等于重绘频率） |
| `-StaleMinutes <分>` | 5 | 超过该时长无事件即判 `[!] STALLED?`，长任务多可改 `-StaleMinutes 10` |
| `-Sessions <N>` | 6 | 会话面板显示最近 N 个 rollout 会话 |
| `-RecentMin <分>` | 10 | RECENT WRITES 面板的时间窗口（最近 N 分钟被修改的文件清单，Top10） |
| `-FreshHours <时>` | 8 | SESSIONS 面板新鲜度窗口：只显示最近 N 小时有事件的活动会话（**进行中的 turn 无视此限制永远显示**），超龄会话折叠为计数提示 |
| `-SessionsDir <路径>` | 自动 | Codex rollout 会话根目录；默认解析顺序：参数 > `$env:CODEX_HOME\sessions` > `%USERPROFILE%\.codex\sessions` |
| `-VsCodeLogRoot <路径>` | 自动 | VSCode 日志根目录；默认解析顺序：参数 > `$env:CODEX_MONITOR_VSCODE_LOGS` > `%APPDATA%\Code\logs` > `%APPDATA%\Code - Insiders\logs`（取存在的第一个） |
| `-Once` | - | 只打一帧后退出（脚本化/截图用） |
| `-OpenLog` | - | 打开当前 Codex.log 后退出（优先用 `code` CLI，未安装时回退系统默认程序） |

### 运行中按键

| 键 | 作用 |
|---|---|
| `空格` | **暂停/继续**：冻结当前画面细读，再按回到最新帧 |
| `r` | 强制重画一帧 |
| `q` | 退出 |

## 三、面板读法

```
Status  : ACTIVE   (no change for 2 m)      ← 总状态 + 距上次实质变化时长
SESSIONS (rollout)  每行一个 Codex 会话
  * sid      ic   status        lastEv  tok    current step / last reply
  * 01a081ac [>]  WORKING       4 s     4.1M   shell_command : git status...
```

| 图标/状态 | 含义 | 你该做什么 |
|---|---|---|
| `[>] WORKING` | 事件流 <45s，**step 列显示此刻在执行的具体命令** | 不用管 |
| `[~] CMD/RUNNING?APPROVAL` | 命令挂起 >45s 未返回：**长任务或在等你批准**（rollout 无审批事件，无法百分百区分） | 切回 Codex 窗口看一眼 |
| `[~] QUIET(long step)` | 无新事件但进程/日志还活着（长推理） | 等 |
| `[!] STALLED?` | 本轮未结束但超 StaleMinutes 无任何动静 | 检查（可能卡死；内存异常增长可看顶部 Mem） |
| `[+] RECENTLY ENDED` | 本轮刚完成（<2min），step 列=最后回复摘要 | 给下一个指令 |
| `[=] IDLE` / `[-] ENDED(old)` | 已完成较久 / 历史会话 | — |
| `*` 标记 | 该会话 cwd = 所监控项目（多项目并存时区分） | — |

**RECENT WRITES** = 最近 `-RecentMin` 分钟内被写入的文件清单（时间倒序 Top10，相对路径）——回答"刚才修改了哪些文件"看这里；清单变化会触发重绘。

SESSIONS 选取规则：候选=最近 24 个 rollout → 按新鲜度过滤（`-FreshHours`，默认 8h；进行中 turn 强制保留）→ 截断至 `-Sessions`（默认 6）行，被隐藏的超龄会话以计数行提示（信息量小的久远会话不占屏）。

底部 ACTIVITY = 项目文件与 VSCode 日志新鲜度；GIT = 分支/未提交改动数/diff 行数；ALERTS = 日志错误行。**注意**：VSCode 的 Codex.log 可能持续刷无害的重复错误（如 `fetch failed`/`ResizeObserver`），脚本已尽量让"同一条老错误"不触发重绘——看到红字关注**新出现**的，而非"有红字"本身。

## 四、日常用法建议

1. Codex 在干活时，PowerShell 窗口挂着监控，只在三种情况切回去：**`[~] ...?APPROVAL`**（等你批）、**`[!] STALLED?`**（卡死排查）、**`[+] ENDED`**（本轮完成验收）。
2. 长批量任务（回测/爬取等）配 `-StaleMinutes 10` 防误报。
3. 想留证据/回报问题：`-Once` 打帧复制文本，或 `空格` 冻结后截图。
4. 本监控台是低成本旁路方案，与官方配额/会话状态页面互补：它不显示配额，只回答"现在要不要我介入"。

## 五、原理与维护要点（改脚本前必读）

- **数据源**：`<sessions root>/YYYY/MM/DD/rollout-*.jsonl`（每事件一行 JSON）。关键类型：首行 `session_meta`(session_id/cwd)；`event_msg/task_started`、`event_msg/task_complete`(last_agent_message)、`response_item/function_call`(name+arguments.command)、`function_call_output`、`agent_reasoning`、`token_count`(info.total_token_usage)。
- **turn 进行中判定** = 最后一个 `task_started` 之后无 `task_complete`；**pending 命令** = 最后 `function_call` 晚于最后 `function_call_output`。
- **重绘指纹**：状态+会话(step/status)+git 计数+内存(32MB 档)+错误行(剥时间戳)+RECENT WRITES 文件名，外加最小重绘间隔 5s。**新增易变字段时切勿进指纹**，否则回到闪屏。
- **环境自适应（v3.4）**：会话根目录与 VSCode 日志根目录均可由参数/环境变量覆盖（见上表）；git 不在 PATH 时 GIT 面板显示 `(git not on PATH)` 而非报错。取分支用 `git symbolic-ref --short HEAD` 而非 `--show-current`，兼容老版本 git。
- **性能**：大项目首轮全量扫描文件（排除 `.git/ node_modules/ .cache/ venv/ bin/ obj/ dist/ build/`），之后每 15s 复用缓存；rollout 与日志均为尾部字节窗口读取，不整文件加载。
- **局限性**：`ACTIVE ≠ 模型百分百在思考`，仅代表进程/日志/事件流最近有活动；等审批与长命令共用 `[~]`；旧格式 rollout 的 session_id 可能为 null（已按文件名 UUID 兜底）；Codex 若更改 rollout 事件 schema，需相应更新解析分支。

## 六、版本沿革

- **v2**：进程+日志+文件+git 旁路快照，每 2s 全量重绘；`branch --show-current` 在老 git 上静默失效。
- **v3**：+rollout 逐会话面板（当前命令/token/`-Once`），修复老 git 与 null session_id 两问题。
- **v3.1**：按需重绘 + Space/r/q 键控 + 60s 心跳。
- **v3.2**：修复错误时间戳假变化导致的"仍闪屏"，重绘最小间隔 5s。
- **v3.3**：新增 RECENT WRITES 面板（`-RecentMin` 窗口内被改文件清单，纳入变化指纹）+ SESSIONS 新鲜度过滤（`-FreshHours`，活跃 turn 豁免）；文件扫描单轮复用。
- **v3.4**（当前）：面向发布的环境自适应——`-SessionsDir` / `-VsCodeLogRoot` 参数、`CODEX_HOME` / `CODEX_MONITOR_VSCODE_LOGS` 环境变量、Code/Code - Insiders 双日志根回退、git 缺失优雅降级、`-OpenLog` 回退系统默认程序。
